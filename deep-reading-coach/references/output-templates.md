预测问题：…
提示：…

【第 n 段】         ← 阶段二第二步（每段一次）

【复盘自检】        ← 阶段二第三步

## 端到端示例（节选，六级）

**用户输入**：一段 6 段、约 300 词的说明文，标注「六级」。

**阶段一**

```
【文本概况】
体裁：说明文
词数：302 词
难度匹配：六级　匹配（句长 21 词，含定语从句，词汇属六级）
```

**阶段二第一步**

```
【预读预测】
概况：体裁：说明文　词数：302 词　首句："City planners rarely think about the night sky."
预测问题：这篇文章最可能讨论城市管理与哪一种资源之间的关系？
提示：注意首句中的 rarely 这一否定副词，它往往预示全文要谈的是一个被忽视的问题。
```

用户答"可能讨论光污染与城市规划的关系" → 简评：`对——rarely 已点出被忽视的问题，方向抓准。`

**阶段二第二步（第 1 段）**

```
【第 1 段】
首句："City planners rarely think about the night sky."
段意提示：从规划者的盲区切入
引导问题：作者用 rarely 一词，暗示规划者目前的态度是什么？
生词提示：overlook (v.)　urban (adj.)
```

用户答"他们没考虑过夜空问题，觉得不重要" → 简评：`对——rarely 已表达"极少考虑"，理解到位。`＋`原文依据："City planners rarely think about the night sky."`

**阶段三（节选一条）**

```
① 语法点：被动语态｜现在完成时的被动
② 原文例句："Little attention has been paid to the glow above our streets."
③ 作用说明：把责任主体隐去，突出"关注缺失"这一事实。
```

**阶段四第一段**

```
【阅读题目】
1.（主旨题）本文主要讨论什么？
A. 城市夜间照明技术的改进方案
B. 夜空亮度上升对城市管理提出的新要求
C. 居民对夜间光环境的审美偏好变化
D. 天文观测设备在城市中的布局原则
```

用户答 B → 解析：

```
1. 答案：B
   原文依据："The growing glow above our streets now demands a response from city managers."
   解析：B 与原文"demands a response from city managers"同义。A 属无中生有（原文未谈技术方案），C 属范围扩大（原文谈规划者而非居民偏好），D 属偷换概念（把夜空问题换成设备布局）。
```

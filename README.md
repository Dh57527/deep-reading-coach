# deep-reading-coach

一个英语深度阅读理解陪练 Skill：给它一段英文文本和一个难度标签（四级／六级／考研），它按固定五阶段带你精读——**预读预测 → 逐段精读 → 复盘自检 → 语言点提取 → 阅读题实战**——最后给出一份学习记录。

核心设计只有一条：**一次只推进一步，等你作答才继续**。不会一口气把答案、译文和语法全倒给你。

---

## 1. 解决的问题

背单词、刷题都能自己来，唯独"精读"很难自己完成，因为：

- **没有反馈闭环**。查完生词、看完译文就觉得读懂了，但说不出这一段在讲什么、作者为什么这样写。
- **答案给得太快**。一次性拿到全文翻译和题目答案，只能记住结论，无法定位自己是在哪一句读偏的。
- **语言点讲解跑偏**。本来只想认识句子结构，结果变成主语、谓语、宾语、定语从句的逐层拆解，读完记不住用法。
- **难度不入档**。拿一篇考研真题当四级材料练，或反过来，练完既没成就感也没提升。

这个 Skill 把精读拆成"先猜—再验证—再自检—再提炼—再验收"的循环，每一步只问一个问题，答完才点评、才走下一步。它不提供译文，逼你回到原文自己找依据。

## 2. 主要功能

| 阶段 | 功能 | 关键约束 |
| --- | --- | --- |
| 一　输入接收 | 校验两项输入，输出文本概况（体裁／词数／难度是否匹配） | 缺文本或缺难度标签只追问缺失项，不猜默认难度、不开工；<80 词先提示偏短；>800 词只处理前 5 段 |
| 二　三步引导 | Pre-reading 预读预测 1 问＋1 条提示；While-reading 逐段精读（首句、段意提示、引导问题、生词词性）；Post-reading 三项自检 | 一次只推一步，严禁合并步骤、严禁提前给答案；生词只给词性不给释义 |
| 三　语言点提取 | 每段 1-3 个、全篇 ≤8 个语法点，每条固定三行：标签＋名称／原文例句／作用说明 | 标签限定七类（时态与体、被动语态、从句引导词、非谓语动词、固定搭配与介词、情态与虚拟、比较结构）；只标点不拆句，不做成分标注与结构树 |
| 四　阅读题实战 | 主旨 1＋细节 2＋推断 1，四选一；先只给题干与选项，作答后才给答案、原文依据与错项类型 | 答案唯一且有原文直接依据；干扰项不照抄原句、不与答案等价；错项须归入偷换概念／范围扩大／无中生有／因果倒置 |
| 五　交互收尾 | 生词数、语法点数、正确率（n/4），加一句可执行的下一步建议 | — |

贯穿全程的交互规则：

- 每个阶段结束给两个选项：`【继续】进入下一阶段　【重新回答】重做当前阶段`。
- 【继续】严格按阶段顺序推进，不跳步；【重新回答】不换文本，等你重新作答后再点评。
- 所有"原文例句／原文依据"逐字取自你提供的文本，不改写、不拼接。

**不支持**：网页抓取、PDF 解析、朗读与语音、整段或逐句翻译、长难句句子成分拆解、图形界面。这些需求请在别的工具里做。

## 3. 安装方法

这是一个纯提示词 Skill，**没有脚本、没有依赖、不需要 Python**，装好即可用。

把 `deep-reading-coach/` 整个文件夹（不是里面的单个文件）复制到任意 Skills 目录：

| 环境 | 放置位置 |
| --- | --- |
| 豆包 / 本机 Skill 目录 | `C:\Users\<用户名>\AppData\Local\Doubao\User Data\Profile 1\.doubao\agent_mode\workspace\.user_skills\deep-reading-coach\` |
| macOS / Linux 常见约定 | `~/.doubao/agent_mode/workspace/.user_skills/deep-reading-coach/` |
| Claude Code 等 | `~/.claude/skills/deep-reading-coach/` |

安装后确认目录里同时存在：

```
deep-reading-coach/
├── SKILL.md                 # 必需：流程规范与约束
├── agents/openai.yaml       # 展示名、简介、默认提示语
└── references/
    ├── difficulty-calibration.md
    └── output-templates.md
```

`SKILL.md` 的 frontmatter 只含 `name` 与 `description`，目录名必须与 `name` 一致（`deep-reading-coach`）。`tests/` 只是本仓库的测试材料，不必放进 Skill 目录。

## 4. 使用方法

**触发**：发一段英文正文，并写明难度标签，三者之一：四级、六级、考研。

```
用 deep-reading-coach 精读这段文本，难度：六级。
<英文正文>
```

**过程中你只需要做两件事**：

1. 回答它每一步的问题（预读预测、每段的引导问题、复盘自检、选择题）。
2. 阶段结束时选 `【继续】` 或 `【重新回答】`。

**几条真实行为，提前知道会更顺**：

- 只发文本不发难度，它只会回一句追问，不会先讲内容。
- 文本不足 80 词，它会先提示"偏短"，等你确认再继续。
- 超过 800 词，它声明"只处理前 5 段"，并按前 5 段统计词数与出题。
- 中途说"直接给答案"，它会提醒你在跳步，要求你选择【继续】按序推进。
- 中途想换文章，回到阶段一重新校验两项输入。

## 5. 输入输出示例

以下取自仓库内 `tests/case-1-cet4.md`（四级，208 词，4 段）的真实测试记录，只保留关键帧。

**输入**

```
难度标签：四级

On many campuses, a new kind of club is quietly growing. Students bring broken
lamps, torn backpacks and old radios to a small room, and volunteers help them
fix the things instead of throwing them away...
```

**阶段一：文本概况**

```
【文本概况】
体裁：说明文
词数：208 词
难度匹配：四级　匹配（平均句长 17 词，无嵌套从句，词汇在四级范围）
```

**阶段二第一步：预读预测（只提问，不解答）**

```
【预读预测】
概况：体裁：说明文　词数：208 词　首句："On many campuses, a new kind of club is quietly growing."
预测问题：这段文字最可能介绍校园里出现的哪一类新社团，它靠什么吸引人？
提示：注意关键词 repair cafes，它是全文的核心名词。
```

**阶段二第二步：逐段精读（每段四行，答完才走下一段）**

```
【第 1 段】
首句："On many campuses, a new kind of club is quietly growing."
段意提示：校园里冒出的新社团
引导问题：quietly 一词让你对这类社团的规模有什么印象？
生词提示：torn (adj.)　volunteer (n.)
```

用户答完后只给一行点评＋一句原文依据，例如：

```
简评：对——quietly 表示"悄悄地"，说明规模在扩散但尚未引人注意。
原文依据："a new kind of club is quietly growing"
```

**阶段三：语言点提取（三条固定格式，全篇 ≤8 条）**

```
① 语法点：被动语态｜一般现在时被动
② 原文例句："Nothing is thrown out unless it is really dead."
③ 作用说明：以物作主语，淡化施动者
```

提取完固定附一行：`以上语法点均取自本文原文，未做句子成分拆解。`

**阶段四：先只给题**

```
【阅读题目】
1.（主旨题）本文主要介绍什么？
A. 校园修理咖啡馆的兴起及其两面影响
B. 大学生丢三落四习惯的成因分析
C. 学校志愿社团经费短缺的解决办法
D. 电子产品维修行业的人才培养路径
```

**用户答"B"之后的解析（错项必须归类）**

```
1. 答案：A
   原文依据："Even so, the number of repair cafes on campuses has doubled in the past three years."
   解析：A 与原文"数量翻倍但仍困难"的两面叙述一致。B 属无中生有（原文未谈丢三落四），C 属范围扩大（经费只是其中一个小问题），D 属偷换概念（把校园社团换成行业培养）。
```

**阶段五：学习记录**

```
【学习记录】
生词数：6
语法点数：8
正确率：3/4
下一步建议：把第 4 段的 Even so 所在句改写成一个让步复句，体会转折位置。
```

## 测试

`tests/` 下有三份不同难度的真实样文与实测记录：

- `case-1-cet4.md`：四级，208 词，4 段
- `case-2-cet6.md`：六级，317 词，6 段
- `case-3-postgrad.md`：考研，531 词，7 段
- `case-4-boundary.md`：缺难度标签、62 词短文两个边界输入
- `test-report.md`：逐阶段实测输出、判定与测试后对 Skill 的修改

校验项：原文引句逐字命中、语言点 ≤8 且每段覆盖、标签限定七类、题型配比 1 主旨／2 细节／1 推断、选项字数接近、干扰项不照抄原句。三份文本全部通过，`quick_validate.py` 校验为 `Skill is valid!`。
